# Contributing to SpongeTube

The canonical contribution and repository rules are in [`.work/GOVERNANCE.md`](.work/GOVERNANCE.md).

Before making a non-trivial change, read:

1. [`.work/PRODUCT.md`](.work/PRODUCT.md)
2. [`.work/ARCHITECTURE.md`](.work/ARCHITECTURE.md)
3. [`.work/GOVERNANCE.md`](.work/GOVERNANCE.md)
4. [`.work/VERIFICATION.md`](.work/VERIFICATION.md)
5. [`.work/ROADMAP.md`](.work/ROADMAP.md)

Use a short-lived branch and a pull request. PR titles and commit messages follow Conventional Commits.

Do not silently broaden scope or encode architecture that conflicts with `.work`. Performance claims require reproducible evidence.
