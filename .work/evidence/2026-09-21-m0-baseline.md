Device and host clocks remain separate domains. No host/device timestamp subtraction is used to manufacture latency metrics.

## Invalid-run history

Earlier M0-F runs were retained as CI artifacts and were not promoted:

- N1 sessions finalized through Android lifecycle during an open rebuffer → correctly reported `PARTIAL / UNCLOSED_REBUFFER`;
- initial API 23 AVD bootstrap exceeded the non-legacy boot deadline;
- API 23 could not use the modern `Android/media` evidence staging path;
- UI text was found to be an insufficient synchronization primitive for measurement finalization.

The final harness resolves these by using API-aware emulator/evidence handling and a signature-gated, target-process `finishIfQuiescent` command. Finalization now occurs on the target main thread only when the real player is not `STATE_BUFFERING`; the reducer was not weakened.

## M0 architectural handoff

M0 `SimpleCache` remains a reference baseline only.

M1 uses the already-frozen Sponge-owned durable extent-store direction:

- immutable extent files under app-private durable storage;
- Room/SQLite metadata, journal, coverage and integrity indexes;
- temp write → fsync/integrity → atomic rename → transactional `PRESENT + VALID` publication;
- PlaybackBridge consumes published Sponge coverage and does not independently refetch Sponge-owned/in-flight coverage.

## Conclusion

M0 has sufficient reproducible evidence to close and hand off to M1.

The accepted evidence demonstrates the laboratory, baseline behavior, compatibility boundary, cache identity and failure observability. It deliberately does not claim that emulator timing represents real-device performance.
