## Generator identity

- FFmpeg: 9.0.2
- Generation source: synthetic lavfi video/audio only
- Recipe: `scripts/media-lab/generate-fixtures.sh`

## DASH conformance

Changes to F1, `manifest.json` or `checksums.sha256` trigger the pinned `Fixture Conformance` workflow. The workflow uses DASH-IF Conformance 3.0.0 at commit `56970b64e0e89454c06b3cc5ca712211b9b1ec62`, retains its JSON result as a CI artifact, and must be green before a fixture-changing PR is merged.

Large/raw validator output is not committed into the repository.

## Android bridge

The Media Lab data listener is exposed to an emulator/USB device with `adb reverse` at `http://localhost:18080/`.

Only the data listener is reversed. Control remains host-only.

Debug source-set Network Security Config permits cleartext for `localhost` only. It does not weaken release/main network security.

`adb reverse` is plumbing for deterministic media tests and is not evidence for VPN/default-route semantics.
